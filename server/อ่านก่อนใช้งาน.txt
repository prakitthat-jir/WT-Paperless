====================================================================
 WT Paperless — ระบบตรวจสอบ แผนกคลังสินค้าและจัดส่ง
 วิธีใช้งาน
====================================================================

■ เริ่มใช้งาน (แนะนำ — ข้อมูลเข้า Excel อัตโนมัติ)

   ดับเบิลคลิกไฟล์   START-WT-Paperless.bat
   จะมีหน้าต่างสีดำขึ้นมา (ห้ามปิด) และเบราว์เซอร์จะเปิดหน้าแอปให้เอง

   กรอกฟอร์ม -> กดบันทึก -> ข้อมูลเข้าไฟล์ WT-Paperless-Data.xlsx ทันที

   เลิกใช้งาน: ปิดหน้าต่างสีดำ


■ เปิดจากมือถือหรือเครื่องอื่นในบริษัท

   1. ดับเบิลคลิก START-WT-Paperless.bat ที่เครื่องนี้ก่อน
   2. ดูบรรทัด "เปิดจากมือถือ/เครื่องอื่น" ในหน้าต่างสีดำ เช่น
         http://10.101.3.211:8080
   3. พิมพ์ที่อยู่นั้นในเบราว์เซอร์ของมือถือ (ต้องอยู่ในวง Wi-Fi เดียวกัน)

   ทุกเครื่องบันทึกลงไฟล์ Excel เดียวกัน


■ ติดตั้งเป็นแอปลงมือถือ / แท็บเล็ต  (ไม่ต้องผ่าน App Store / Play Store)

   ในแอปมีเมนู "ติดตั้งเป็นแอป" อยู่แถบซ้าย (ไอคอน 📲)
   เปิดหน้านั้นจะเห็น QR code + ที่อยู่ + ขั้นตอนของแต่ละระบบ

   iPhone / iPad  (ต้องใช้ Safari เท่านั้น)
      1. เปิด Safari ไปที่ที่อยู่ของระบบ (หรือส่องกล้องที่ QR)
      2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) ตรงกลางแถบล่าง
      3. เลื่อนหา "เพิ่มไปยังหน้าจอโฮม" -> ตั้งชื่อ WT Paperless -> เพิ่ม
      -> ได้ไอคอนสีเขียว เปิดแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์

   Android  (แนะนำ Chrome)
      1. เปิด Chrome ไปที่ที่อยู่ของระบบ (หรือส่องกล้องที่ QR)
      2. แตะปุ่ม 3 จุด มุมขวาบน
      3. เลือก "เพิ่มไปยังหน้าจอหลัก" หรือ "ติดตั้งแอป"

   คอมพิวเตอร์ (Chrome / Edge)
      กดไอคอนติดตั้งที่แถบที่อยู่ แล้วเลือก "ติดตั้ง"

   หมายเหตุ
      • เป็น Progressive Web App — อัปเดตอัตโนมัติเมื่อไฟล์แอปเปลี่ยน
        ไม่ต้องส่งขึ้นสโตร์ ไม่มีค่าธรรมเนียมรายปี
      • มือถือยังต้องอยู่ในวง Wi-Fi เดียวกับเครื่องแม่ เพื่อบันทึกลง Excel
        ถ้าออกนอกวง ระบบจะเก็บข้อมูลไว้ในเครื่องก่อน แล้วส่งให้เองเมื่อกลับเข้าวง


■ (ไม่บังคับ) เปิดโหมด HTTPS — สำหรับให้ Android ติดตั้งเป็นแอปเต็มรูปแบบ

   ปกติระบบเปิดผ่าน http ซึ่ง iPhone ติดตั้งได้ปกติ แต่ Android จะได้
   แค่ทางลัด ถ้าต้องการให้ Android ติดตั้งเป็นแอปจริง (และใช้ออฟไลน์ได้)
   ต้องเปิดผ่าน https ทำได้โดย

      1. ให้ฝ่าย IT ออกใบรับรอง (certificate) ของเครื่องแม่
      2. สร้างโฟลเดอร์ชื่อ  WT-Paperless-Cert  ไว้ข้าง ๆ ไฟล์นี้
         แล้ววาง  cert.pem  กับ  key.pem  ลงไป
      3. เปิด START-WT-Paperless.bat ใหม่ — จะมีบรรทัด https:// เพิ่มขึ้นมา
         (พอร์ต 8443)
      4. นำใบรับรองไปติดตั้งในมือถือแต่ละเครื่องด้วย

   ถ้าไม่ทำข้อนี้ ระบบยังใช้งานได้ครบทุกอย่างตามปกติ


■ ใช้งานแบบไม่เปิดตัวช่วย

   ดับเบิลคลิก WT-Paperless-WebApp.html ได้เลย ใช้ได้ครบทุกอย่าง
   แต่ข้อมูลที่กรอกจะเก็บอยู่ในเบราว์เซอร์เครื่องนั้น ไม่เข้าไฟล์ Excel
   (เมื่อเปิดผ่าน START-WT-Paperless.bat อีกครั้ง ระบบจะถามส่งข้อมูลที่ค้างให้)


■ ไฟล์ต่าง ๆ ในโฟลเดอร์นี้

   Paperless of Warehouse & transportation.xlsx
       ไฟล์ฐานข้อมูลเดิมจาก AppSheet — ระบบใหม่ "ไม่แตะต้อง" ไฟล์นี้เลย
       ข้อมูลเก่า 40,636 รายการถูกคัดลอกไปแสดงในแอปแล้ว (ดู/พิมพ์ได้ แก้ไม่ได้)

   WT-Paperless-Data.xlsx
       ไฟล์ใหม่ เก็บเฉพาะข้อมูลที่กรอกผ่านแอปตั้งแต่วันนี้เป็นต้นไป
       คอลัมน์เหมือนไฟล์เดิมทุกประการ

   WT-Paperless-Data.json
       ข้อมูลชุดเดียวกัน เก็บไว้ให้ระบบอ่าน (ห้ามลบ)

   WT-Paperless-Images\
       ลายเซ็นที่เซ็นผ่านแอป

   WT-Paperless-Backup\
       สำรองข้อมูลอัตโนมัติทุกครั้งที่บันทึก (เก็บย้อนหลัง 40 ครั้งล่าสุด)

   WT-Paperless-WebApp.html      หน้าจอแอป
   WT-Paperless-Server.js        ตัวช่วยบันทึกลง Excel
   START-WT-Paperless.bat        ปุ่มเปิดระบบ

   WT-Paperless.webmanifest      ข้อมูลแอปสำหรับติดตั้งลงมือถือ (ห้ามลบ)
   WT-Paperless-SW.js            ตัวช่วยให้เปิดแอปแบบออฟไลน์ได้ (ห้ามลบ)
   WT-Paperless-Icons\           ไอคอนแอปบนหน้าจอโฮม (ห้ามลบ)


■ ปัญหาที่พบบ่อย

   • หน้าต่างสีดำขึ้นว่า "Node.js is required"
       -> ติดตั้ง Node.js จาก https://nodejs.org (เลือกปุ่ม LTS) แล้วลองใหม่

   • บันทึกแล้วขึ้นว่า "ยังส่งเข้า Excel ไม่ได้"
       -> เปิดไฟล์ WT-Paperless-Data.xlsx ค้างไว้ใน Excel อยู่ ให้ปิดก่อน
          ข้อมูลไม่หาย ระบบเก็บไว้ให้ กดเมนู ☰ แล้วกดปุ่มส่งข้อมูลที่ค้าง

   • เปิดจากมือถือไม่ได้
       -> เครื่องที่เปิด .bat ต้องเปิดค้างไว้ และต้องอยู่ Wi-Fi วงเดียวกัน
          ถ้ายังไม่ได้ ให้แจ้ง IT เปิด Firewall พอร์ต 8080

   • ติดตั้งลงหน้าจอโฮมแล้ว แต่เปิดมาขึ้นว่าเชื่อมต่อไม่ได้
       -> เครื่องแม่ยังไม่ได้เปิด START-WT-Paperless.bat หรือมือถือหลุด Wi-Fi
          ของบริษัท กลับเข้าวงแล้วเปิดใหม่ ข้อมูลที่กรอกค้างไว้จะถูกส่งให้เอง

   • iPhone หา "เพิ่มไปยังหน้าจอโฮม" ไม่เจอ
       -> ต้องเปิดด้วย Safari เท่านั้น (Chrome บน iPhone ทำไม่ได้)

   • อยากพิมพ์เป็น PDF
       -> ในหน้ารายการ ติ๊กเลือกรายการที่ต้องการ แล้วกด "พิมพ์ / PDF"
          ในหน้าต่างพิมพ์ ให้เลือกเครื่องพิมพ์เป็น "Save as PDF"
